# Bundled demo data

The included player season rows are a small, static 2023-24-style snapshot for
product demonstration. The recent-game rows are deterministic synthetic examples
generated by `scripts/generate_sample_data.py`; they are not official historical
box scores and must not be presented as current NBA data.

This deliberate offline fallback keeps the portfolio demo reliable. The data
access layer is separated from ingestion so a licensed or public live provider
can replace these CSVs later without changing analytics or UI code.
